# PortFolio Lab

Laboratorio de empresa virtualizado, montado y documentado por **Jose Martínez Sánchez**, Técnico Superior en ASIR.

👉 **Ver la web:** https://josemartinez76.github.io/portfolio-lab/

## Qué incluye
- **Active Directory** con dos controladores de dominio (DC01 y DC02) replicados, DNS interno, DHCP y GPO/SYSVOL.
- **Firewall OPNsense** con tres zonas (servidores, usuarios y DMZ), DHCP Relay, NAT y reglas de mínimo privilegio.
- **Servidor web** Ubuntu + Apache publicado en la DMZ.
- **Tickets de soporte resueltos y documentados paso a paso:**
  - puesto sin IP (APIPA)
  - fallo de inicio de sesión por DNS
  - salida a Internet bloqueada
  - permisos NTFS
  - caída de un controlador de dominio
  - web no accesible desde Internet
